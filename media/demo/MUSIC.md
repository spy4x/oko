# Music for the oko demo video

`music.opus` is the music the oko demo video's encoder lays under the video.

- Title: Persistence
- Author: Rafael Archangel
- Album: Library Music Vol. 1 (2017)
- Source:
  https://freemusicarchive.org/music/Rafael_Archangel/Library_Music_Vol1/Rafael_Archangel_-_Library_Music_Vol1_-_21_Persistence
- Copy downloaded from Wikimedia Commons:
  https://commons.wikimedia.org/wiki/File:Rafael_Archangel_-_21_-_Persistence.ogg
  (file: https://upload.wikimedia.org/wikipedia/commons/e/e2/Rafael_Archangel_-_21_-_Persistence.ogg)
- Licence: CC0 1.0 Universal, a public domain dedication
  (https://creativecommons.org/publicdomain/zero/1.0/). Both pages above state it. It allows
  commercial use with no attribution; this file names the source anyway.

The file here is 90 seconds of the track starting at 0:28, where it is already steady, re-encoded
to Opus at 96 kbit/s, stereo, with all metadata removed and no other change. The video's encoder trims
it to the video's length, sets its level, and fades it in and out.
